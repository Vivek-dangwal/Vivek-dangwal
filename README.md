### 👋 About Me

I'm a Computer Science graduate (DCRUST, 2026) who builds ML systems from the model level up — not just calling APIs, but implementing the internals: manual autoregressive decoding, quantization, vector indexing algorithms, retrieval pipelines. My focus is **LLM inference optimization and retrieval systems (RAG/vector search)**, with a secondary track in computer vision and graph-based ML. I like understanding *why* a system is fast or accurate, not just that it works — which is why most of my projects are built from scratch rather than wrapped around existing libraries. Fluent in English (C2) and conversational in French (B2). Currently looking for Data Scientist / AI-ML Engineer roles where I can work close to the model layer.

|---|---|
| **[nano-llm](https://github.com/Vivek-dangwal/nano-llm)** | LLM inference engine from scratch — manual autoregressive decoding, per-channel INT8 quantization (**54.3% RAM reduction**), dynamic KV-caching, micro-batching |
| **[nano-vec](https://github.com/Vivek-dangwal/nano-vec)** | Vector search engine from scratch (IVF, HNSW, Product Quantization), benchmarked against FAISS, served via FastAPI |
